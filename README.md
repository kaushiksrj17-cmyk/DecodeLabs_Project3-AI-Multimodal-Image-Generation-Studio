# 🎨 DecodeLabs Project 3 — AI Image Generation Studio

A professional AI-powered multimodal image generation studio built
using Python, Streamlit, and Google Gemini.

## 🚀 Features

- AI image generation
- AI prompt enhancement
- Multiple visual style presets
- Aspect ratio selection
- Resolution controls
- Inference steps
- Guidance scale
- Fixed seed support
- Negative prompts
- Image upload
- AI image description
- Ask questions about uploaded images
- Image-to-generation-prompt conversion
- Image generation from multimodal prompts
- Image gallery and history
- Image download
- Image deletion
- Error handling and user-friendly UI

```text
Uploaded Image
      ↓
Gemini AI Analysis
